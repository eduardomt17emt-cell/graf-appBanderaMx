# graf-appBanderaMx

Aplicación Web que administra los colores verde y rojo de la Bandera de México, desarrollada como práctica integradora de la materia **Graficación** (Ingeniería en Sistemas Computacionales, TecNM), aplicando los temas 1.1 (interfaces Web), 1.2 (publicación colaborativa) y 1.3 (control de versiones).

## Descripción

La aplicación muestra los tres colores de la bandera mexicana:

- **Verde (Esperanza)**: controlado mediante un slider (0-255)
- **Blanco (Unidad)**: fijo, con el escudo nacional al centro
- **Rojo (Sangre de nuestros héroes nacionales)**: controlado mediante un slider (0-255)

Cada recuadro de color muestra su código hexadecimal actualizado en tiempo real.

## Prompt utilizado en ChatGPT

Se solicitó a ChatGPT generar una interfaz Web con tres archivos separados (HTML, CSS y JS) que replicara el diseño de tres columnas de la bandera de México, con sliders para controlar los tonos de verde y rojo, mostrando el código hexadecimal de cada color y un espacio central fijo en blanco con el escudo nacional.

## Tecnologías utilizadas

- **HTML5** — estructura de la aplicación
- **CSS3** — diseño de tres columnas tipo bandera
- **JavaScript** — lógica de conversión a hexadecimal y actualización de color en tiempo real
